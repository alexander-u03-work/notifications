∿ RaggiesNotify Курсовой проект

Сервис уведомлений

Raggies Notify получает события приложения через RabbitMQ и обрабатывает их для отправки уведомлений.

Как это работает

  1. Главный сервер

    Публикует событие приложения.

  2. RabbitMQ

    Ставит событие в очередь и передаёт его сервису.

  3. Raggies Notify

    Обрабатывает событие и формирует уведомление.
